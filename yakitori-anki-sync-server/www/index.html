Use this exact URL in Anki, including the trailing slash. Keep the server on your local network or reach it through a VPN such as Tailscale — it speaks plain HTTP.

Anki desktop

  1. Open Tools → Preferences → Syncing (or Network on older versions).
  2. Enable the self-hosted / custom sync server and paste the Sync URL above.
  3. Enter username anki and the password from this app’s details, then sync.

AnkiDroid and AnkiMobile

  1. AnkiDroid: Settings → Advanced → Custom sync server. Set both the collection and media URLs to the Sync URL above (media can also be the same URL with /msync).
  2. AnkiMobile: Settings → syncing → custom sync server. If it cannot connect on your LAN, toggle “Allow Anki to access local network” off and on in iOS settings.
  3. Sign in with the same username and password, then sync.
